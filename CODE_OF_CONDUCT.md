# Code of conduct

Monitone follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good intent, keep discussions about the work, and do
not harass anyone.

This applies to issues, pull requests, discussions and anywhere else you
represent the project.

## Reporting

If someone behaves unacceptably, report it privately to the maintainer through
[Security > Report a vulnerability](https://github.com/Nusi42/Monitone/security/advisories/new)
(start the title with "Conduct:"), or use GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
function. Reports are handled confidentially. The maintainer may remove
comments, close threads or block people who break this code.
