# Changelog

## 1.0.0 (2026-10-31)

The first release of Monitone.

**Every program plays on the speakers of the screen it is on.** Move a video
from your left screen to your right screen, and the sound moves from the left
speakers to the right speakers. Monitone runs quietly in the notification area
and does this for you, for every program.

- **Speakers per screen:** choose which speakers belong to each screen.
- **One speaker set, left and right:** with a single pair of speakers, programs
  on the left screen play on the left speaker and programs on the right screen
  on the right one, or the sound follows the window smoothly while you drag it.
- **App rules:** keep a program on fixed speakers wherever its window is, for
  example your voice chat on the headset, or leave a program alone entirely.
- **Live overview:** see every program that is playing sound right now, which
  screen it is on and where it plays.
- **Light on resources:** the settings window is only loaded while it is open.

### Download

Pick one:

- `Monitone-1.0.0-x64-setup.exe`: setup, recommended
- `Monitone-1.0.0-x64.msi`: MSI package, for example for managed PCs
- `Monitone-1.0.0-x64.zip`: portable, unpack and start `Monitone.exe`

Both installers install for the current user only and need no administrator
rights. Monitone needs Windows 10 or 11 and the Microsoft Edge WebView2
Runtime, which almost every PC already has.

Windows SmartScreen may warn that the publisher is unknown because Monitone
is not code-signed yet. Choose *More info*, then *Run anyway*.
